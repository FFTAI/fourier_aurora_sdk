# Maintainer Documentation

This directory contains design history, implementation contracts, test
profiles, dependency notes, and release work for SDK maintainers. It may
describe superseded decisions or unfinished work and is not the supported user
API.

User-facing documentation is maintained bilingually at:

- [`README.md`](../../README.md) / [`README_CN.md`](../../README_CN.md)
- [`overview.md`](../overview.md) / [`overview_CN.md`](../overview_CN.md)
- [`cpp_api.md`](../cpp_api.md) / [`cpp_api_CN.md`](../cpp_api_CN.md)
- [`python_api.md`](../python_api.md) / [`python_api_CN.md`](../python_api_CN.md)
- [`examples_and_clients.md`](../examples_and_clients.md) /
  [`examples_and_clients_CN.md`](../examples_and_clients_CN.md)

Internal material:

- `adr/`: architecture decision records, including superseded decisions;
- `command_contract.md`, `result_codes.md`: implementation contract details;
- `sdk_architecture.md`, `fourierdds_transport.md`: internal architecture;
- `dependency_discovery.md`, `source_id_registry.md`: deployment/maintainer notes;
- `testing.md`, `release_checklist.md`: verification and release tracking.
